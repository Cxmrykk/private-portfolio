Road Defect Detection & Measurement System

Worked in a team of 6 at Optik Consultancy to build DCPM-ADMS (Automated Defect Measurement System). Involves a cutting edge computer vision (ML) pipeline using YOLOv8 and SAM2 for detection and pixel-precise segmentation. Extracts GoPro GPMF metadata to create metric-scaled Bird's Eye View projections for accurate measurement using homography. Just stick a GoPro on your car and you're set.

Python Flask YOLOv8 SAM2

Utilitarian Chat UI

"HTML Chat" is an LLM chat interface that I built for myself which promotes function over form. It allows you to edit, manage and customise multiple conversations at once and leverages the browser for custom tooling, including code execution. Supports any OpenAI-compatible endpoint (LiteLLM, OpenRouter) including local models (Ollama). All data is locally stored in the browser so that only the LLM sees your conversations.

JavaScript IndexedDB LLMs RAG

"yt-dlp" Tube

A data-privacy centric YouTube frontend that runs on your own server. Relies on "yt-dlp" to extract youtube content and scrape direct video and audio URLs, allowing the server to proxy/cache content while stripping away ad-injection and telemetry. Omits YouTube's algorithmic engagement and only shows videos from channels you're subscribed to. A general-purpose media downloader is built-in, and SponsorBlock is included.

Python Flask yt-dlp SponsorBlock

Raspberry Pi Automotive Display Mirroring

Ever used CarPlay or Android Auto? If your car's not more than 10 years old, then surely you've at least heard of it. "BerryAuto" is a project of mine allowing you to use your car's head unit as an external display. Internally, it reverse engineers the proprietry Android Auto protocol to display custom content to the screen using a Raspberry Pi 4 (or any Linux-based SBC with H.264/HEVC hardware accelerated encoding). Touch input is supported.

C++ Linux EVDI FFmpeg

About
