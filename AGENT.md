# Agent Coding Guidelines

- **Modularity:** Split source code files into smaller, logical modules whenever they exceed ~200-300 lines or handle multiple independent concerns.
- **JavaScript:** Use ES6 modules for code separation. Keep a single entry point that orchestrates the initializations.
- **CSS Architecture:** Organize CSS into logical categories and compose them via `@import` in the main stylesheet.
- **Completeness:** Never truncate files. Always provide the full, untruncated code for every modified or created file.
